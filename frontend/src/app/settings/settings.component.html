Open in

Open stills in a desktop app such as Photoshop. Needs the Footage Archive Opener, installed once per computer — the browser can't start desktop apps on its own.

@for (opt of openInOptions; track opt.label) { }

Setup

macOS Windows 
bash ~/Downloads/footage-archive-opener-macos.sh --root /Volumes/footage --origin {{ openIn.appOrigin }}
powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\footage-archive-opener-windows.ps1" -Root \\192.168.2.230\footage -Origin {{ openIn.appOrigin }}

--root is where the footage share is mounted on that computer; --origin lets Chrome open the Opener without asking every time (restart Chrome afterwards). Run with --uninstall / -Uninstall to remove it.

Opens a dialog from the Opener that checks the share and Photoshop.
